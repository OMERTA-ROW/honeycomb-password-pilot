# Honeycomb Password Pilot

Owner authorizes sending this existing product plan to Lovable and starting a private development preview. Keep unpublished; do not deploy, enable public sharing, charge subscriptions or connect paid services. Preserve requirements in a project specification and implementation checklist. Clearly distinguish working features from mocked interfaces and native-platform work that is not implemented. No actual customer passwords or remote host access in this initial preview. Create Honeycomb Vault, separate from Honeycomb Terminal and Omni/Evolution. Canonical owner plan: https://app.notion.com/p/403c1161030681438741f869fd1244d6 . Implement an initial responsive preview with dark charcoal, warm amber, subtle hexagonal vault branding, tagline "Your access. Under your control." Simple status and obvious next action. Account list and guided password update batches: choose independent replacements per account or secure generation preferences, preview/authorize batch, pause for MFA, verify before completed, report completed/waiting/unsupported/failed and recovery guidance. Use sample credentials only and label simulation; never imply actual password changes. Roadmap: supported desktop browser extension/companion first, mobile autofill where feasible, on-device encryption and encrypted sync with server unable to decrypt, device-backed keys, biometrics/hardware keys, stronger export/new-device verification, auto-lock, session revocation, appropriate key rotation, passkeys. Key management/recovery require independent review; never log passwords/recovery codes/exports. No universal site control or assumed Google Password Manager write-back.
Include Digital Honey Pack (not Dye Pack): decoy credentials for controlled service; usage alerts and observed time/address/event details, no destructive payload/hack-back, false positives and offline-copy limitations. Recovery dashboard from another device, authentication not solely dependent on lost device; future-access revocation and supported OS lock guidance, no promise to recall exposed secrets or whole-device control. Show confirmed/pending/offline/failed actions. Enrolled device cryptographic identity, authenticated check-ins, last-seen/public IP/permitted location with timestamps/accuracy and stale labels. Locate/Find Nearby feasibility depends on OS/UWB/hardware; five-to-ten feet is a test goal, no guaranteed offline/unpowered tracking, reset persistence, retroactive installation, Find My access, or unmasked IP.
Incident evidence export should distinguish observation/suspicion/corroboration, tamper-evident events and collection history, no personal attribution from IP alone or guaranteed legal outcomes. Proposed pricing only: individual $4.99/month or $49/year, 10 devices one user; household $9.99/month or $99/year, six private vaults/30 devices. VPN $7.99/month or $79/year possible later subject to costs, outside initial core. Malwarebytes affiliate interest only, no issued affiliate link/partnership or license bundle. Optional discreet Terminal promotion card in Vault menu/companion area only, never interrupt security/password/recovery flows. No reverse Vault advertising in Terminal. Record security/native implementation work honestly rather than marketing as complete. Test implemented preview workflows and report limitations.
